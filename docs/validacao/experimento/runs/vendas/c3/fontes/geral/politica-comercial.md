# Política Comercial — Distribuidora Aurora (revisão 2025)

Aprovada pela Diretoria Comercial em 10/02/2025.

1. **Descontos.** O vendedor pode conceder até **12%** de desconto sem aprovação. Entre
   12% e 20%, é necessária a aprovação do gerente comercial. Acima de 20%, só com
   aprovação da diretoria.
2. **Clientes.** Vendemos para pessoas jurídicas e, desde 2025, também para pessoas
   físicas profissionais (eletricistas autônomos), que compram pela loja web.
3. **Crédito.** Pedido acima do limite de crédito exige análise pelo financeiro em até
   **1 dia útil**.
4. **Preço.** A tabela de preços é única para todos os canais.
5. **Comissão.** As regras de comissão são definidas pelo financeiro e aprovadas pela
   diretoria anualmente.
6. **Dados de clientes.** Os dados de clientes só podem ser usados para marketing com
   consentimento explícito (LGPD).
