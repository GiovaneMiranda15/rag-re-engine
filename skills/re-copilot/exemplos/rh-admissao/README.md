# Caso sintético: admissão e onboarding (Drogarias Caliandra)

Empresa e dados **fictícios**. Caso criado por um agente sem acesso à skill, para testá-la em um
projeto puxado por RH, DP, Jurídico e Operações. Tem armadilhas: falsos positivos que uma boa
análise não deve apontar como problema.

- `escopo.md`, `fontes/`: o que o participante recebe.
- `oraculo.md`: fatos que um stakeholder simulado usa para responder às perguntas.
- `mudancas/`: comunicações para o teste de manutenção, entregues só depois da documentação.
- `gabarito.md`: o que uma análise ideal encontra. **Nunca entregue ao participante nem indexe.**

Protocolo de uso: `docs/validacao/README.md`.
